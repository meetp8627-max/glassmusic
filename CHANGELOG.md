# Changelog

All notable changes to GlassMusic are listed here. The newest version is on top.
Add a section for each new version before releasing; its text becomes the public release notes.

## [2.1.0] - 2026-11-10

A faster, lighter update with a new Lite mode for slower phones.

### New
- **Lite mode** (Settings > Performance). Choose Auto, Lite or Full. Auto turns on for phones with limited memory and swaps the heaviest visual effects for simple, fast ones.
- **Open-source licenses** screen in Settings.
- The **version number** now shows on the Home screen and in Settings.

### Improvements
- Much smoother scrolling and tab switching on low-end phones.
- One shared song menu replaces the per-row menus, so long lists open faster.
- Long lists show the first songs and a **Show all** button.
- Smaller cover images and lower memory use.
- The player no longer redraws the whole screen while a song plays.
- Release builds are now optimized and signed, so updates install over each other.

## [2.0.0] - 2026-11-08

A completely new interface.

### New
- A glass tab bar that shrinks as you scroll and expands when you tap it.
- Home with a featured track, "Made for You" mixes, a trending carousel and Recently Played.
- A **reorderable queue**: drag songs to change the order.
- Settings with a display name, Recently Played switch, sleep timer and clear-data options with confirmation prompts.
- Volume slider and playback speed controls in Now Playing.
- Artist pages and a quick actions menu for every song.

### Requirements
- Android 13 or newer. Older phones can use GlassMusic Classic.
